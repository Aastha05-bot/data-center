Key Terms to Know

Learn these words before we dive in — they'll help you build a mental model of how data centers work.

🖥️ Data Center A building full of computers (servers) that store data and run apps. Think: "a hotel for the internet"
⚡ UPS Uninterruptible Power Supply — a battery that keeps servers running during power cuts. Bridges the gap before generators start
💧 CRAC Computer Room Air Conditioning — cools the servers so they don't overheat. Uses water or refrigerant to remove heat
🔋 Generator A diesel engine that provides power during longer outages. Can run for days if refueled
🌐 Bandwidth The amount of data that can move through a network connection at once. Like lanes on a highway
♻️ E-waste Discarded electronic equipment that contains toxic materials. Old servers become e-waste
